# Privacy Policy — GitHub PR Tab Group

**This extension does not collect, transmit, sell, or share any user data.**

The GitHub personal access token you provide is stored exclusively in your
browser's local extension storage (`chrome.storage.local`) on your device. It
is used only to authenticate requests to `api.github.com` to fetch your pull
requests, and is never sent anywhere else. Your settings and sync state are
likewise stored only locally.

No analytics, tracking, or third-party services are used. The developer has no
server and receives no data of any kind. Removing the extension deletes all
stored data.
